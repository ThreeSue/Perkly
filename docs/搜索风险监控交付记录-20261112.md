# 搜索风险监控交付记录

> 2026-11-12：下文是早期搜索阶段快照，已由 [统一内容风险管控后端验收](统一内容风险管控后端验收-20261112.md) 覆盖本轮范围、测试数和开发部署状态。

本轮只交付搜索风险监测；工作区已有集章、画像、短信、AI 配置等变动不计入本轮成果。

## 实现

- 实时词库 BLOCK / REVIEW / ALLOW，Unicode NFKC 与大小写归一，白名单完整匹配；后台新增、修改、停用、删除及审计。
- 门店、优惠券、附近门店、推荐搜索与用户地点联想接入。保存原文、命中词、真实 APP 用户或游客、请求路径、时间与状态。
- 独立事务写风险记录，BLOCK 随后的业务异常不会回滚记录；推荐内部同词查询去重。
- 后台按状态或用户筛选分页、详情、忽略/确认及原因审计；处理加行锁，已处理记录拒绝重复处理；账号统计按非空 userId 去重。
- 平台 search:risk:view / search:risk:manage 权限及菜单注册。无自动封禁，沿用用户管理封禁/解禁；公开 APP 接口带令牌时仍校验身份与封禁，避免降级为游客。
- 增量迁移 deploy/search-risk-20261112.sql；移动端专用汇总及 api-docs/搜索风险监控接口-20261112.md 更新。

## 验证与交付边界

测试类 SearchRiskTest、SearchRiskPersistenceTest，使用独立数据库 perkly_ai_regression_20261106；测试自行执行增量建表并清理生成的风险词、记录及审计。日志 logs/test/search-risk-final-20261112.log，详细结果见 target/surefire-reports。

测试覆盖规则匹配/停用/白名单、请求内去重与原文、先记录再拦截、业务回滚后记录保留、真实 APP 身份、非平台或缺权限拒绝、人工复核审计及重复处理拒绝、旧令牌封禁/解禁（含公开路径）。

尚未验收：开发主库迁移及运行中服务部署、管理网页联调、移动端真机测试；不宣称 Docker 或远程仓库已更新。后台接口测试以 Spring 集成调用为主，尚未逐条通过真实 HTTP 登录流程验收。大数据量统计当前会加载匹配记录去重，需在实际规模增长前改为数据库聚合。

本模块未引入 houbb 默认敏感词库；本地 sensitive-word 0.29.5 发布 POM 声明 Apache License 2.0，当前用运营配置词库实现明确规则即可。未修改 Music Platform。
