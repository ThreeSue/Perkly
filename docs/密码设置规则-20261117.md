# 新设置密码规则

旧密码及其哈希不迁移、不批量重置，登录不检查新复杂度规则。仅在注册、修改、重置、管理员创建账号时校验。

统一由 PasswordPolicy 校验：8至64个字符（Java/JS UTF-16长度），UTF-8不超过72字节；大写、小写、数字、特殊符号至少三类；无空白和控制字符；无连续4位数字/字母顺序倒序、相同字符、横向键盘序列；不包含常见弱密码简单变形；不与账号或手机号相同。

短信注册及重置在校验通过后才消费验证码。商家旧申请重提仍验证原密码，不对历史申请密码强制升级。系统内部随机申请凭据不作为用户设置密码。

## 重置接口调整

以下接口原有身份、业务参数保持，额外必须提交 password（新密码），省略将返回密码规则错误；不再默认重置为123456。

- /admin/merchant/account/resetPassword：merchantId、password
- /admin/merchant/backendAccount/resetOwner：id、password
- 门店账号 resetPassword：storeId、id、password，适用于运营及商家入口

管理端已改为密码输入弹窗，取消不会发送重置请求；账号状态操作不要求密码。成功响应保持原有结构。新密码不在响应返回。
