## 发现的问题

1. **回复没有按卡片类型区分措辞。** 门店、本人持券、订单的 `purchasable=false` 被模型泛化成“不可购买”。应只对券模板解释领购资格，对门店说明地址/营业状态，对订单说明支付状态和金额。
2. **订单回复显示内部数据库ID。** 本次说“订单（ID: 1164）”，应优先使用订单号或“这笔订单”，内部ID只作跳转参数。
3. **越权券/订单请求的错误语义不够准确。** 均已拒绝、未泄露记录，但沿用业务服务的 HTTP 200 + code=500，建议后续统一为明确的无权访问或不存在错误。

本轮只新增测试及记录，没有修改上述生产逻辑。测试发现的问题仍待处理。
