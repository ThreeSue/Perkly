# 商家记录权限与日期选择调整

2026-10-23，仅修改 apps/merchant 手机核销前端；用户需求截图及后续依赖见 [需求补充](../需求补充-20261023.md)。未触碰本轮开始前已有的导航折射改动。

## 改动

- 删除本人/店长切换和旧的店长统计占位，统一核销记录页。已验证的逐店员工角色派生 self（本人）、逐店店长角色派生 store（全店，不加本人筛选）；没有身份、门店、正确商家归属或角色授权时返回 null。没有接入假身份，当前运行仍未认证。
- `utils/merchant-records.ts` 为纯授权策略与北京时间日期快捷范围；`stores/session.ts` 持有只读外部上下文并提供未来认证适配器的整体替换/清除入口。复制授权以避免外部对象改动悄然提升权限，不从URL、存储或顾客/管理员会话恢复角色。
- 日期复用 Cool cl-select-date + cl-picker-view；自定义有标签和键盘入口的按钮，日期范围只在确定时写回页面。向组件传范围副本，避免其内部滚动草稿直接修改已提交数组。今天/近7天/近30天均按北京时间、含首尾日期；不选未来。
- 搜索临时输入与清空可用，正式搜索按钮因接口缺失禁用；券类型按要求保留空白禁用区域。
- 商家普通操作按钮最小44px、长文案换行、日期触发器最小46px；日期弹层两个操作等宽，保持蓝灰白与既有Cool组件。
