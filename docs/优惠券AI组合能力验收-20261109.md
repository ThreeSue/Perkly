## 实现边界

模型负责将请求映射为受控查询/修改计划，后端执行数据查询、计算、范围校验与确认。查询增量支持继承、覆盖、明确清除；范围令牌与操作人和页面范围绑定。统计和销量/核销组合结果核实后交给模型组织对话正文，不再直接回显统计模板。没有开放任意 SQL、任意接口调用或无限自主执行。

## 口径与授权

模板售价字段非空且默认0，业务校验将未填值归零；0为免费，正数为付费。分母保留商家、门店、名称、类型、状态和数据权限，仅移除售价条件。分母为0返回null占比，不显示0%或发生除零。权限每次重查，令牌不能扩大权限。

部分测试曾误用没有优惠券菜单权限的门店员工账号，失败原因是账号类型/角色前置不满足，随后改为项目既有的受限商家员工配置验证门店隔离；门店员工无权限的拒绝断言保留。

## 已发现并处理的问题

| 分类 | 证据 | 处理 |
| --- | --- | --- |
| 数据能力缺失 | 原COUNT没有售价过滤和分子分母 | 增加类型化售价条件、真实统计、稳定正文及结构化countResult |
| 理解/合并错误 | 首次真实测试新增上架与券型后丢掉付费条件，2款误代1款 | 后端缓存范围传入解析上下文；空ANY对象不清除旧价格条件；只有明确clear可清除 |
| 意图歧义 | 「把付费改成零元领取」被当作批量改价 | 查询上下文优先识别筛选修正；不确定则澄清筛选还是修改，不能假定写入 |
| 目标上下文不足 | 一轮全量真实测试中，两个既有多轮用例误识别选中券，组合汇总遗漏共同券名 | 提供后端权限校验过的唯一选中券信息，禁止把历史搜索关键词作为完整券名；要求组合指标保留目标 |
| 时间口径错误 | 真实销量/核销汇总中模型将最近30天换算为含首尾31天，原测试未断言日期 | 提取relativeDays，后端按含今天的N个自然日计算，并补充起始日期断言 |
| 交互缺口 | 错误只显示底部、切换券仍保留删除确认卡 | 错误加入聊天；所有待确认操作在选择变化时清除 |
| 执行规则限制 | 代金券不能改折扣；无核销权限不能查核销 | 保留真实限制，后续可改问其他指标；汇总分别报告失败项 |

## 尚未覆盖或不支持

- 历史模板快照、任意规则筛选、任意分组、自定义占比分母、同比/环比、多步骤不同日期基准，未接入数据能力；不应伪装已完成。
- 修改适用门店、固定有效期、销售起止时间、叠加规则、内容项及封面等完整页面字段仍需已有表单，不是所有页面能力都已接入自然语言。
- 全部角色在真实后台页面中的完整端到端流程、所有审核/上下架组合、澄清过程中任意任务切换、任意多工具组合尚未全面验证。
- 模型可能误解或遗漏自然语言语义。受控参数和回归减少风险，无法证明任何问法都不会漏提条件。当前仅对已识别但不支持的条件明确阻止或澄清。
- 先前图片模块的空套餐内容校验契约问题属于另一模块，本轮没有修复或宣称其测试通过。
