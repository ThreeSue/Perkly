# H5底部液态导航接入 · 2026-10-23

## 实现范围

客户端与商家端的H5主导航已接入实时背景位移折射；沿用五端独立应用、原有三个tab路由、switchTab和全部业务接口。微信小程序保留此前半透明导航和原有运动，不接入SVG、背板滤镜或H5放大/色散效果。白色光斑、白色反光渐变均未恢复。

## 材质与交互

- 外壳与选中透镜在同一背板采样平面处理，绕开旧深色父层隔离背景的问题。曲面位移场使页面背景在边缘弯曲，不使用模糊。蓝灰底色和深色标签保证阅读，平坦单色背景上的折射本来就不明显。
- 按住或滑动时，选中透镜沿阻尼弹簧放大：纵向增加约58%，横向乘0.88，再叠加速度形变。透镜上下可超出外壳约3–7px；松手弹性收回，跨tab继承运动。
- 背板裁切使用外壳与透镜的SVG联合轮廓，允许透镜露出外壳；按钮的语义、点击区域、顺序、文字布局不随外观变形移动。
- 选中曲面上的R/G/B通道采用略有差异的真实背景采样偏移，形成薄边色散；另有0.8px、低透明度的环境彩边，使单色背景也略有边缘色相。它不是白色高光，也不把整块透镜染成彩色。
- 图片位移场仅在导航尺寸变化时生成；移动时更新SVG位置/尺寸/采样强度，不逐帧Canvas绘制或PNG编码。扩张弹簧650ms内停算，导航位移弹簧900ms内停算；静止无常驻动画循环。
- 增强仅针对当前已验证的Chromium内核，其他浏览器使用可读的既有半透明回退。减少透明度/强制高对比时停用折射；减少动态效果时不放大、不回弹。未承诺Safari/Firefox真实折射。
