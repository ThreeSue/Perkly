# 客户端商家与优惠券浏览接入记录

更新时间：2026-10-20

## 已接入的只读能力

- `GET /app/merchant/category/list`：读取后端公开行业分类。
- `POST /app/merchant/store/page`、`GET /app/merchant/store/info`：浏览、搜索、筛选门店及查看门店/所属商家公开资料。
- `POST /app/coupon/page`、`GET /app/coupon/info`：浏览优惠券、按门店或券类型筛选、查看规则和适用门店。
- 首页使用后端门店和优惠券数据；首页关键词搜索同时查询门店和优惠券；门店列表按分类接口的`parentId`展示一级分类及其二级分类筛选，并分页；门店详情展示门店信息和分页的适用优惠券；优惠券列表与详情只读展示。请求错误按后端 message 显示，不回退到本地样例。
- 首页四个快捷入口保留；“团购”进入优惠券列表，其余入口进入门店发现。门店列表接口按行业分类筛选，并未定义外卖/演出/民宿等服务场景筛选条件，因此其余入口暂不执行场景过滤。
- 门店卡以门店为单位展示。门店 ID、商家 ID、优惠券模板 ID、发布记录 ID分开传递；价格按接口约定以整数分格式化为元。
- 本次不包含领券、购券、订单、模拟支付、券包、核销、关注、商品服务和活动接口，客户端不显示这些操作已成功。

## 优惠券接口前端调用位置

| 后端接口 | 前端封装 | 调用位置 |
|---|---|---|
| `POST /app/coupon/page` | `apps/client/api/discovery.ts` 的 `listCoupons()` | 首页 `pages/index/home.uvue`；优惠券列表 `pages/discover/coupons.uvue`；关键词搜索 `pages/discover/list.uvue`；门店适用券 `pages/discover/merchant.uvue` |
| `GET /app/coupon/info?id={券模板ID}` | `apps/client/api/discovery.ts` 的 `getCoupon()` | 优惠券详情 `pages/discover/coupon.uvue` |

以上调用只用于公开优惠券的分页和详情浏览；当前没有领取或购买接口。

## 真正联调前仍需确认

1. H5 开发代理仍是 `127.0.0.1:8001`；微信开发者工具/手机需要使用设备可访问的电脑局域网地址或已部署 HTTPS 域名。正式小程序还需配置请求域名；接口返回的图片域名也需可访问并按微信规则配置。
2. 后端演示数据应满足公开查询条件：商家和门店均启用；优惠券须有平台渠道的通过审核、已上架发布记录，且发布版本与模板规则版本一致，并至少关联一家营业门店。
3. 当前门店分页返回门店行，不是去重后的商家列表。若产品要“一商家一张卡”或独立商家主页，需要后端提供商家粒度列表/详情，或确认现有返回字段与去重规则。
4. 首页四个服务入口没有对应的后端筛选字段；若要求外卖、团购、电影演出、民宿分别筛选，需要后端补充稳定的服务场景/业务类型字段及映射规则。
5. 如后续启用商品/服务、活动、关注、领取或购券流程，仍需对应只读/写入接口契约。

本记录只描述前端代码接入，不代表已对真实后端、微信开发者工具或真机完成联调。本轮未请求后端服务、未运行测试或编译。
