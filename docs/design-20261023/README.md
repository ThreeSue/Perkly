# 券管家手机端设计与验证 · 2026-10-23

本轮为前端视觉与交互实现。适用 apps/client 与 apps/merchant，保留 uni-app x、Vue 3、Cool Unix、五端独立、原有路由及所有数据接口。没有修改后端、创建假业务数据、登录测试账号或发布应用；已有联调数据继续保留。

## 已交付

客户端首页、门店卡、优惠券卡、发现列表/详情、券包、订单列表、个人中心、登录/注册/找回密码布局统一为蓝灰白。共享色源移入 packages/shared/styles/commerce-tokens.scss，商家早期黄色同步为蓝灰白；其他三端原主题不变。统一最大680px内容宽度、20px边距和文字层次，缺图明确说明，不使用虚构店铺照片。

根据用户参考图实现清透悬浮胶囊。独立透镜响应触点位置与移动速度，高光方向实时变化，支持拖动、果冻伸缩、轻微倾斜、惯性越界与回弹。点击不会在按下时瞬移，触摸与鼠标入口和键盘使用同一弹簧。跨tab继承本端内存运动，页面内容不必等待动画结束。H5约16ms、小程序约32ms一步，静止停算，单次最长900ms；H5减少动态效果时直接归位。材质无模糊，H5仅增强饱和/亮度，小程序无SVG滤镜、WebGL或backdrop-filter依赖；属于苹果风格的材质与运动模拟，不等同苹果系统原生光学渲染器。

触摸取消恢复原页（最新H5鼠标外部释放行为见文末），合成鼠标与tap去重，路由失败恢复原项。导航支持Enter/Space和aria-current。保留pages.json的原三个tab及switchTab，隐藏系统底栏；二级页面保持返回链路。搜索增加有可访问名称的清空按钮，并恢复输入焦点。

## 七维评审与实质优化

| 维度 | 发现与落实 |
| --- | --- |
| 视觉层次 | 品牌/分区/卡片/说明分级；券包与个人中心以凭证卡建立重点，不增加余额或假统计 |
| 布局节奏 | 统一宽度与边距；首页失败区压缩；商家统计改为紧凑横排 |
| 色彩 | 两端统一蓝灰白；次要文字提高对比度；修复深色卡片与导航图标低对比 |
| 细节 | 清透亮边、内反光、触点高光与有限弹性；门店图改为固定比例，名称可换行 |
| 信息密度 | 六个状态改为3列两行；窄屏分类文字不再断为两行；订单按钮保留独立宽度 |
| 易用性 | 点击/拖动/键盘都能导航；取消、边界、惯性、路由失败和搜索清空有恢复行为 |
| 一致性 | 两端共享材质/色源/数学，分别保留本端路由与权限；错误与未登录不伪装成功 |

第一轮截图评审后，实质修正了导航图标选中颜色、首页失败区高度、个人中心结构、固定高门店卡、筛选布局和商家主题。第二轮增加真实弹簧状态与跨页连续运动；窄屏复核再修复分类标签、券包按钮挤压与小程序重复键盘属性。
