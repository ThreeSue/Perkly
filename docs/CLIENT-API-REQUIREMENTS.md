# 客户端 API 需求清单（旧草案归档）

本文件早期曾列出建议接口路径，其中包括购物车、真实微信支付和退款流程。它们与 2026-10-20 收到的《券管家3.0_数据库表规划(1).md》不一致，**已不作为当前需求，也不要转发给后端作为接口要求**。

当前应使用 [接口覆盖与后端需求报告](./接口覆盖与后端需求报告.md)。该报告以已知数据库规划和真实接口资料为依据，只说明所需能力，不臆造 URL、请求字段或响应 DTO；具体接口契约由后端组员确认后，客户端再接入。

3.0 范围约束：

- 购券订单采用后端模拟支付；客户端不能自行生成支付成功或券码。
- 数据库规划没有购物车；旧模板购物车和客户端进程内购物车仅为历史演示，不列入本期功能。
- 当前真实接口资料见 [后端联调接口文档](./BACKEND-API-20261013.md)。
