# 商家导航速度响应与切页性能

用户反馈小程序切页卡顿，随后明确否定彩色描边，要求透镜上下大小和折射强度随移动速度变化。本轮仅修改导航、共享运动/折射函数、定向测试和记录；并行聊天对真实商家API/核销业务的修改继续保留。

## 当前效果

已移除商家谱色image、PNG和生成器；商家H5旧伪元素保持禁用。`packages/shared/src/glass-navigation.js` 导出的 `merchantLensResponse(velocity, expansion)` 直接表达映射关系：

```js
v = min(abs(velocity), 2); // px/ms，非有限值回到0
scaleX = 1 - 0.08 * v;
scaleY = 1 + 0.28 * v + 0.08 * clamp(expansion, 0, 1.08);
refraction = 24 + 18 * v;
```

额外纵向伸展和折射强度均随速度线性增加，速度上限防止快速甩动失控。按住不移动只有8%的基础扩张。手指静止64ms后，速度以60ms时间常数衰减；松手后按弹簧速度继续调整，停稳回到基础值。

H5的真实背景位移与透镜几何消费同一函数，位移只更新SVG采样参数，不逐帧重建纹理。小程序消费相同的几何函数，但本轮没有新增背景采样；**小程序真实动态背景折射仍未完成**，不能用形变代替折射验收。

## 性能修改

原先小程序回弹虽只用一条16ms计时器，但每一步仍更新响应式数据并经过组件渲染和逻辑/视图通信。现在以相同阻尼弹簧数学一次生成有界关键帧，交给 `UniElement.animate` 播放；依据 [DCloud官方动画API](https://doc.dcloud.net.cn/uni-app-x/api/dom/unielement.html#animate)，微信目标映射为WXS+transition，完整指定每个关键帧的transform，使用linear插值。逻辑层仅安排一次收尾通知，不再逐16ms写导航组件。

触摸拖动保留合并后的更新，取消/松手消费末触点。页面隐藏清理收尾通知并取消本组件动画，下一Tab根据时间线采样当前位置和速度续接；快速反向、再次触摸可打断。窗口未resize时复用已测量的固定导航尺寸，减少切页后的测量通信。字体/颜色、三项Tab和业务权限没有在此轮改动；原生button边框公共修复按并行聊天约定追加 `uni-merchant-button` 类。
