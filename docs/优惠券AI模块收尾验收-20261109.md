## 页面操作与AI能力矩阵

| 页面操作 | 对话支持与复用路径 | 边界 |
| --- | --- | --- |
| 查询、筛选、详情 | 查询名称/券型/模板、审核、发布状态/商家/门店/售价；详情在对话内 | 任意规则筛选和历史模板快照不支持 |
| 款数、售价占比、销量、核销、排名、选中券比较 | 后端真实指标；模型组织正文；范围令牌继承 | 不支持同比环比、任意指标或跨步骤不同日期基准 |
| 新建 | 模型起草；核对后保存；调用现有新增服务 | 不凭空创建业务字段，复杂内容可回原表单 |
| 名称、说明、售价、门槛、抵扣、满减、折扣、优惠上限 | 同一字段修改目录，缺值追问、预览、确认 | 按券型限制；清空优惠上限由原表单操作 |
| 每人限领、库存 | 有效整数；发行总量和剩余可领区分 | 不猜库存口径；不限量切换可用原表单 |
| 有效期 | 固定开始/结束和领券后天数；切换方式显示清除影响 | 日期必须含明确时刻；清空使用原表单 |
| 领取购买时间 | 开始、结束可独立修改或一起修改 | 沿用结束晚于开始及启用时未过期规则 |
| 同享优惠 | 允许/不允许，经预览确认 | 不新增优惠叠加算法 |
| 适用门店 | 全部营业门店或完整名称列表；授权和商家归属校验 | 同名门店使用原表单，不猜ID |
| 内容项 | 完整清单替换，调用既有内容/商品关联服务 | 增减单项需完整清单或原内容编辑器，不猜其余项目 |
| 封面、生图、素材库 | 对话识别后给出原编辑入口；复用已有生图和素材组件 | 打开入口不等于已生成；本轮不另做生图模型、额度或素材服务 |
| 启用、停用、送审、撤回、审核、上下架 | 原发布服务和权限；确认时重新核对版本 | 商家不能审核；审核中/已上架的规则修改仍受限制 |
| 删除 | 原删除检查；必要时禁用并删除事务；批量逐条结果 | 已发放或有历史关联的券不可删除 |
| 券型及完整表单字段 | `EDIT_FORM`复用原表单 | 创建后商家、发放渠道不允许随意更换；没有新增复制业务 |

运营沿用模板权限及原审批授权；商家沿用`coupon:*`与实时岗位/门店范围。任何新增入口不授予权限。

## 渐进重构

- `CouponAssistantInterpreter`：类型化意图解析与本条筛选移除证据检查。复用原模型和Key，不做业务写入。
- `CouponAssistantContext`：选中目标、查询令牌、范围绑定、继承/覆盖/清除及不支持条件。
- `CouponAssistantQueries`：可见范围、价格与状态过滤、模板统计、真实销量/核销和排名。
- `CouponAssistantEdits`：统一字段目录、类型约束、修改差异、门店名称解析及内容映射。新建和更新共用内容映射，删除重复的新建内容转换分支。
- `CouponAssistantNarrator`：模型自然回复、受控统计占位符、预览事实及数字校验。金额/日期同时来自核实后的变更，不只读取一句预览标题。
- `CouponAssistantService`：保留对话协调、澄清/改口、授权与确认事务。保持原控制器和DTO兼容入口，避免破坏已有调用。
- `CouponTemplateService.validatePreview`与保存共用`validateInput`，复用金额、日期、商家、门店和内容校验；确认仍执行完整业务服务，预览不替代最终校验。

未搭建通用Agent框架，也未为每一种说法添加新正则。已有库存兼容分支仍保留，本轮没有宣称所有历史分支都已彻底消除。数字来源检查不是完整语义证明，模型仍可能误解或错配事实。

## 管理端共用优惠券编辑器

运营端新增和编辑改为复用商家端「左侧实时预览＋右侧三步表单」。共用标题/步骤、底部导航、字段分组规则和弹窗样式；已有商家券面预览组件直接复用。运营端保留所属商家选择、原字段及保存校验，商家端权限与门店边界不变，主题分别沿用运营蓝色和商家配色。商家选择组件增加只读的`selected`事件供预览显示名称，不改变原`change`参数或接口。

AI的`EDIT_FORM`和`EDIT_COVER`仍进入页面的原新增编辑组件，现在进入这套共用布局；封面请求直接定位第三步，普通表单从第一步开始，生图/素材服务没有复制。此界面复用没有修改后端接口或数据库结构。

浏览器实测两端新增弹窗三步前进/后退，1280×720桌面及640×800窄屏没有弹窗横向溢出；记录为前端`logs/shared-editor-operator.log`、`logs/shared-editor-merchant.log`，截图位于`output/playwright/shared-editor-*.png`。类型检查、生产构建通过，分别见`logs/shared-editor-typecheck.log`和`logs/shared-editor-build.log`；机械界面检查结果为空。此项截图导航检查不等同于全部券型保存组合已验收。

最终构建另经真实隔离后端完成运营新增满减券保存、券名和商家名称实时预览（`logs/shared-editor-create.log`）；编辑代金券使用说明并保存成功（`logs/shared-editor-save.log`）；真实模型识别封面编辑请求并进入第三步，AI生图入口可见（`logs/shared-editor-handoff.log`）。测试数据由独立夹具清理；未发起云端图片生成。
