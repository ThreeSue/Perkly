# AI优惠券封面接口与操作说明

适用：统一管理端的商家、门店工作台及平台运营优惠券创建/编辑。移动端首版不新增AI入口。后端 `cool-admin-java-test`，管理端 `cool-admin-vue-8.x`。

## 配置与启用

IDEA → 后端运行配置 → Environment variables 设置 `BAILIAN_API_KEY`，重新加载Maven并重启后端。IDEA变量不会自动传给其他终端或Docker进程。密钥不填前端，不提交Git。可选私有配置为 `config/ai.local.yml`，格式参考同目录example；真实文件已忽略。

已锁定Boot 3.5.16、Spring AI 1.1.8、Springdoc 2.8.9，Java目标17。北京空间地址在AiProperties中配置，已经包含compatible-mode/v1，不再重复拼接v1。文本验证使用qwen3.8-flash；图片使用qwen-image-3.0的专用Spring AI ImageModel适配器。当前表单提示词由确定性模板构造，不额外付费调用文本模型。

首次启动默认关闭AI、每商家每日10次、估算单价未配置。运营进入“AI图片控制台”开启，设置允许模型、默认额度、商家覆盖额度。空覆盖额度继承默认值，0禁止新请求。单价留空不估算，不等于免费。权限和菜单由WorkspaceInitializer注册，不自动授予已有岗位。

关闭AutoTable的部署先执行 `docs/sql/ai-coupon-cover-20261106.sql`，依赖原商家素材迁移；无需导入全量数据库。持久化原有上传目录和 `assets/ai-recovery`，不能将后者映射为公共文件目录。生产反向代理应继续转发原上传URL。

## 操作

运营可在“AI图片控制台 → 功能设置 → 允许的图片模型”勾选 `qwen-image-2.1-turbo` 并保存。优惠券封面弹窗重新打开后，可在图片模型下拉框选择快速模型或原有模型。两者均支持生成和基于原图完善，额度仍按商家合计，费用仍使用控制台配置的统一估算单价。

1. 在优惠券创建/编辑表单填写券名、类型；套餐/体验/兑换券补全真实商品服务名称及数量，运营先选择所属商家。
2. 点击封面旁“AI生成封面”，自动读取当前尚未保存的表单，显示可编辑提示词。无需重复填写已有信息，缺失信息直接提示在原表单补全。
3. “生成一张/按提示词重新生成”不传原图；从历史选择“以此图继续完善”后，“基于所选图完善”会真实传入原图Base64。默认1024×1024，每请求一张。
4. 每张成功图片自动进入所属商家的素材库。候选、原图、新版本、提示词、父图及任务历史持续保留，关闭、刷新、重登录后可查。
5. 点击“选用封面”才回填封面和素材ID；仍须保存原优惠券表单，并沿用提交审核及上架流程。取消、失败或查看历史均不会替换原封面；审核页面不提供代生成入口。
6. 素材选择支持全部来源/用户上传/AI生成。运营的“本商家素材库”对应当前券所属商家；平台原文件空间继续保持原归属。被优惠券或门店引用的素材仍不能删除。AI素材归档不物理删除历史文件，历史选用会恢复归档素材。

## 鉴权与通用约定

运营前缀 `/admin/ai/images`；商家及门店前缀 `/merchant/governance/ai/images`。以下以 `{prefix}` 表示两者。使用现有Authorization及X-Workspace登录机制，不能混用身份。

所有生成接口要求 `ai:image:generate`，并同时检查本次优惠券新增或编辑权限：运营 `coupon:template:add/update`；商家/门店 `coupon:create/update` 及 `material:view`。选用、编辑原图、重试存储再次校验权限和商家归属。门店范围必须在当前账号授权内。商家账号不能通过merchantId访问外商家数据。

所有响应为 `{code,message,data}`；成功code=1000。业务拒绝也可能采用HTTP200配合业务code，必须同时检查code。分页输入 `pageNumber=1,pageSize=20`，pageSize 1~100；任务页面及素材接口返回 `{list,total,pageNumber,pageSize}`。日期时间按现有系统序列化约定，每日额度按北京时间。

## 表单及任务接口

| 方法及路径 | 入参 | data |
|---|---|---|
| POST `{prefix}/prompt` | Draft正文 | prompt、merchantName、storeNames |
| GET `{prefix}/quota` | merchantId | merchantId、day、limit、used、remaining、enabled、keyConfigured、models |
| POST `{prefix}/create` | Create正文 | Task |
| GET `{prefix}/info` | merchantId、id | Task |
| GET `{prefix}/page` | merchantId、pageNumber、pageSize | Task分页，按新到旧 |
| POST `{prefix}/select` | merchantId、couponId（新增时不传）、id任务ID | Task，调用方用url及materialId回填 |
| POST `{prefix}/retry-storage` | 同select | 当前Task，仅补存已有生成结果 |
| GET `{prefix}/materials` | merchantId、pageNumber、pageSize、keyword、categoryId、source | 所属商家素材分页 |
| GET `{prefix}/categories` | merchantId | 分类数组id、name |

Draft字段：`couponId`（编辑时原券ID）、`merchantId`、`name`、`type`、`description`、`scopeType`（0全部营业门店/1指定）、`storeIds`、`contentItems`（name、quantity、itemDescription），及可选minSpend、discountAmount、deductAmount、discountRate。券类型CASH/DISCOUNT/FULL_REDUCTION/PACKAGE/EXPERIENCE/EXCHANGE。仅传白名单，不上传整个实体。提示词结合真实券名、类型、商家、门店和商品内容；未指定商品的金额券采用抽象券面，不猜测商品。

Create示例（替换为实际已授权商家ID）：

```json
{
  "requestId":"image-request-20261106-001",
  "mode":"GENERATE",
  "model":"qwen-image-3.0",
  "prompt":"为咖啡体验券生成正方形封面，仅展示手冲咖啡，干净背景。",
  "draft":{
    "merchantId":1,"name":"手冲咖啡体验券","type":"EXPERIENCE",
    "scopeType":0,"storeIds":[],
    "contentItems":[{"name":"手冲咖啡","quantity":1,"itemDescription":"现磨咖啡体验"}]
  }
}
```

编辑图片使用 `mode=EDIT`，额外传 `parentTaskId`。原任务须属于同商家且已STORED；不接受任意URL、外商家图或未入库图作为参考。GENERATE不能传parentTaskId。prompt空时使用后端模板；非空5~4000字。

Task包含：id、merchantId、merchantName、actorName、requestId、couponId、parentTaskId、parentMaterialId、mode、model、prompt、status、materialId、url、archived、durationMs、estimatedCost、errorMessage、createTime、completedAt。只在图片已成功生成且配置过单价时返回estimatedCost；不是实际云账单。不返回密钥、供应商结果正文、参考图Base64或临时签名URL。

source取ALL/UPLOAD/AI。历史source空值归入UPLOAD；分类0表示未分类，不传表示全部分类。既有 `/merchant/governance/materials/page` 同样增加source并在素材返回source、aiTaskId、parentMaterialId；原调用参数保持兼容。

## 幂等、额度、失败处理

requestId为8~64位字母数字下划线或横线。按商家+身份类型+操作人+requestId唯一；同请求同正文返回同任务，不再预占额度。同requestId更改正文拒绝409。网络断开后必须核对原请求或以相同requestId及完全相同正文重试，不自动生成新编号。管理端会暂存未确认提交，提供“核对上次提交”。

一次受理预占一次商家每日额度；校验失败不预占。失败及未知结果也保留占用，避免重复收费风险。额度满拒绝429；禁止模型或跨商家拒绝403；未配置服务拒绝503。并发预占在首个一致性读取前锁定现存商家行，额度行存在时按主键锁定，兼容现有Flex事务管理器，不依赖Spring隔离级别声明生效。

| 状态 | 含义/前端处理 |
|---|---|
| QUEUED | 已受理排队，刷新任务即可 |
| RUNNING | 已开始一次云端生成，关闭窗口不取消 |
| GENERATED / STORING | 已知生成成功，等待/正在保存素材 |
| STORAGE_FAILED | 云端已成功，只重试保存已有图；不重新生成、不扣新额度 |
| STORED | 已永久入素材库，可以预览、选用或基于此图完善 |
| FAILED | 已知失败；原封面保留，新请求须用户明确发起 |
| UNKNOWN | 超时、服务端异常或进程中断，云端结果未知；不自动重发生成 |

同步云端调用关闭自动重试；QUEUED状态才会认领。结果先写本机非公开恢复日志和数据库，再下载永久保存；临时图片URL不交给前端。素材保存失败每60秒补存，手动重试也只补存。原云URL过期且本地未保存时可能仍无法恢复，保留失败记录供运营核查，不能冒充自动恢复成功。服务关闭暂停新请求和排队任务；在途请求继续处理已知结果。商家禁用策略只限制新受理，不撤销已受理任务。

## 运营控制台接口

均为 `/admin/ai/console`，必须 `ai:manage`。

| 方法及后缀 | 入参/输出 |
|---|---|
| GET `/settings` | enabled、allowedModels、supportedModels、defaultDailyLimit、estimatedUnitPrice、keyConfigured、textModel；不含Key |
| POST `/settings` | enabled必填、allowedModels数组、defaultDailyLimit 0~10000、estimatedUnitPrice可空0~10000且最多6位小数；成功data空 |
| GET `/policies` | merchantId、merchantName、enabled、dailyLimit可空的数组 |
| POST `/policy` | merchantId、enabled必填、dailyLimit可空继承默认 |
| GET `/tasks` | merchantId可选、status可选、pageNumber/pageSize；Task分页 |
| GET `/usage` | merchantId可选、startDay/endDay yyyy-MM-dd可选，默认近7天，最多31天，分页 |
| GET `/audit` | pageNumber/pageSize；操作审计分页 |

usage行：merchantId、merchantName、day、requests受理次数、success已知生成成功数（含待入库）、failed、uncertain、estimatedCost已知成功且定价任务之和、unpricedImages未定价成功图片数。audit行：id、actorId、actorName、merchantId、merchantName、taskId、action、detail、createTime。费用为任务创建时单价快照；不以当前单价改写历史。
