# 商家欢迎页已有账号入口

欢迎页去掉原来的白色次级登录按钮，保留唯一的黑色“申请商家入驻”主按钮；原按钮位置下方使用小字按钮“我已有账号，去登录”，打开现有商家登录页。店长和员工共用同一登录方式，员工账号由商家后台开通。

H5 浏览器在390px和320px宽度下均确认只显示一个主按钮、没有白色次级按钮或横向溢出；登录文字触达高度44px。点击登录文字进入登录页，登录说明同时覆盖店长与员工，点“返回上一步”回到欢迎页。未出现页面脚本错误或写请求。
