# 商家微信小程序液态玻璃适配方案

2026-10-24。本文仍记录原生快照与 WebGL 折射的后续研究路线，不代表真实背景捕获或性能已经通过。微信开发者工具已安装；HBuilderX 5.26 编译商家端成功，模拟器已显示商家工作台。正式商家导航目前采用半透明中性玻璃与物理弹簧交互，未接入本文件设想的原生背景采样或 Shader 折射。

## 产品与接入边界

商家三主页面保持第三套黑白灰布局。正式导航保持工作台、核销记录、我的三项及既有switchTab行为。首阶段四Tab探针只测运动，不能直接进入正式路由。正式接入前仍先提供实验效果对比。

保留深色图标和文字、清透胶囊、按下抬升、速度拉伸及松手弹簧吸附。白色光斑继续关闭；色散只作独立可控的光学参数。按钮、焦点和可点击标签由正常小程序节点承载。

## 主路线：分块原生快照 → RGBA → WebGL

1. 在独立微信样机先验证Skyline，不先切正式应用。uni-app x的Skyline支持仍属实验阶段，必须检查Cool组件、布局、日期弹层、滚动与安全区。
2. 将实际页面中小范围、稳定的内容块分别作为snapshot子树，例如身份行、单个功能行、日期字段、反馈行；不会把整页包成一个不断截图的子树。背景层、裁剪关系及滚动坐标需一并记录。
3. 只请求与导航扩张包围盒相交或即将进入该区域的块。以原生快照RGBA数据拼接导航窄条纹理，并匹配原页面背景、祖先裁剪、圆角与层级。导航Canvas、按钮及弹层不进入背景采样源，避免递归。
4. 内容未变时缓存块位图。滚动优先更新块在采样窗口中的位置；新块进入或内容改变时才失效和采样。截图尚未完成时采用版本校验，禁止旧页或旧滚动位置的结果覆盖新纹理。
5. 快照请求串行且最多一个在途；合并失效请求，设有界缓存并逐出离开区域的块。不能以整页截图后裁窄条来声称实现了局部采样。

微信官方类型确认snapshot实例可导出arraybuffer/rgba，但没有裁剪区域参数。小范围来自子树结构本身，不是虚构crop参数。真实尺寸、像素方向、预乘alpha、跨层传输和回读成本均需验证。上传前缩小纹理不等于降低了原生截图回读成本。

## 光学与交互

- 将上游的位移贴图生成、光学片元和RGB采样配套移植，保留其参数、通道和neutral point关系；不把当前解析SDF简化探针当作原版完整效果。
- WebGL Canvas只绘制胶囊与选中透镜覆盖区，外部透明；背景采样需覆盖按压扩张和折射偏移的额外边距。
- 同一运动状态驱动位置、宽高、曲率和Shader采样，保持外壳、选中透镜和标签坐标一致。运动持续时更新uniform，稳定后停止请求动画帧。
- 当前四项运动核心须先参数化为tab数量，再应用到正式三项；点击、拖动释放、取消和路由失败恢复均沿用现有行为约定。
- 触摸事件与运动保留在组件内部，逐帧运动不经Vue响应式状态或setData传回页面；业务路由仅在选项确定时提交。WXML标签状态可低频更新，Canvas更新由自身动画帧驱动。实际触摸事件跨层与绘制延迟仍需测量。

## 复用边界

原生组件负责Canvas、纹理、触摸和资源生命周期；纯模块负责光学参数与弹簧计算；页面只注册背景块和导航项。继续通过wxcomponents和现有.uvue壳连接，不给正式小程序引入React/DOM捕获。背景提供器需与renderer分离，保留受控RGBA输入用于逐项排错。

页面隐藏/卸载停止动画和快照调度，清除在途回调的提交资格并释放GPU纹理；重新显示按当前尺寸及数据重建。弹层打开时不能用过期背景制造错误折射，弹层需保持导航之上的正确层级。

## 若主路线失败

备选是对这三页已拥有的真实数据和视觉原语做同源Canvas重绘，仅提供导航覆盖区纹理；它不能自动获得任意原生节点的实际像素，字体、裁剪、控件状态和图片同步会增加维护成本。必须单列为替代方案并展示差异，不用彩条、静态背景或普通透明模糊冒充完整要求。

如果Skyline/快照与现有页面不兼容，且同源重绘也不能满足视觉与性能要求，应如实记录该限制；不能擅自把降级外观作为已完成验收。

## 验证顺序与门槛

1. 先跑真实文字和分隔线跨过导航的折射开关对照，验证背景与页面位置一致、无自拍递归。
2. 再测原版光学移植与三项运动：按压、快速反向、拖出边界、取消、吸附、切页和返回。
3. 再测整条链路：快照回读、跨层传输、拼接、上传、绘制以及滚动纹理滞后。动画目标60FPS，但不能以Shader单项CPU耗时代替整链路结果，也不能在未实测时承诺达标。
4. 静止后快照、上传、绘制停止增长；反复切页无持续内存增长。缓存预算根据实际像素尺寸制定，不能只报逻辑分辨率。
5. 分别记录微信开发工具和iOS/Android真机结果。当前已验证商家应用编译及模拟器页面显示；独立探针的 WebGL/背景纹理链路和真机性能仍未测，不能把现有结果外推到它们。
