# 统一排序优化

更新日期：2026-10-27

运营端的商家行业分类、门店类型、系统菜单、字典项、部门增加“调整顺序”入口。商家网页端同步菜单、字典和部门的公共组件，沿用原有权限，不额外开放平台管理权限。移动端本次未改动。

编辑弹窗隐藏手填排序号；原有排序字段继续保存于数据库，新增条目的默认值沿用原逻辑。点击“调整顺序”加载当前模块完整列表（字典按当前字典类型），面板不分页，可以拖动或点击上移、下移，点击保存后生效。取消时确认是否放弃修改。树形列表只能同级调整，不改变归属；部门原有调整上下级的工具保留为“调整部门层级”。

统一组件：`src/plugins/crud/components/order-manager.vue`；排序计算：同目录 `order-model.ts`。已有模块升序、降序规则保持不变。只对发生位置变化的同级组重新生成顺序数，只发送ID和排序字段，不携带其他业务字段。

保存复用各模块已有list/update接口及权限，写入前比较ID、父级和排序快照，发现变化则重新读取。当前逐条update不具备事务原子性；请求中断可能部分保存，组件不提示成功并重新加载实际数据。保存前的快照比较也不能防止检查之后发生的并发修改。以后如果需要多人同时高频维护，应增加带版本校验的后端批量事务接口。

验证：`node --test tests/order-manager.test.mjs`，覆盖同级重排、升降序、循环/重复/遗漏/跨父级数据、根部门保护、显式保存、权限不足、并发变更及中途失败。所有数据均为内存测试，没有操作业务数据库。两个前端分别执行类型检查和构建；真实账号页面操作仍需联调验收。
