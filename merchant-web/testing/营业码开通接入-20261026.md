# 商家网页端营业码开通接入

更新日期：2026-10-26。

## 结果

登录页提供两个入口：

- 申请商家入驻：说明前往客户端或商家核销端小程序完成手机号验证、申请、查询和领取营业码。没有伪造小程序二维码或跳转地址，正式入口信息待平台提供。
- 已有营业码，开通账号：验证申请时同一手机号 → 选择申请 → 填营业码和账号密码 → 确认开通 → 返回登录，回填用户名但不回填密码。不自动登录，不自动创建门店。

新申请不再从网页提交。历史申请的账号密码重提兼容弹窗保留，但不能切回首次申请或调用auth/register；历史审核通过文案不再承诺自动开放经营，而是指引领取营业码并开通正式账号。

## 接口

独立公共Axios实例，沿用开发/生产baseUrl，无经营Token拦截器、刷新或注销副作用，不输出请求参数日志：

- GET /merchant/auth/captcha
- POST /app/merchant/onboarding/smsCode
- POST /app/merchant/onboarding/verify
- POST /app/merchant/onboarding/list
- POST /app/merchant/onboarding/info
- POST /merchant/auth/activate

入驻手机号凭证只存在组件内存，关闭、离开、重新验证和成功开通时清理。短信60秒倒计时；账号和密码按文档检查长度、空白及UTF-8字节数。存在多份申请时显式选择，再核对所选申请和营业码匹配才提交。未审核、驳回、码过期和已开通状态不显示开通表单。

网络异常或成功响应格式异常时不直接重试开户，先查原申请详情；已ACTIVATED则返回登录，否则取得状态后再继续。后端最终负责一次性激活、手机号归属及并发约束，前端状态不替代后端鉴权。
