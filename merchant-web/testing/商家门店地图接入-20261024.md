# 商家网页端腾讯地图接入与验证

日期：2026-10-24

## 使用入口

- 左侧菜单 **我的门店地图**：查看当前商家的全部筛选结果，支持关键词、公共门店类型和营业状态筛选。
- 营业为绿色，停用为灰色；蓝色数字为点聚合，点击可展开。点击门店标记或列表可联动查看资料、详情和位置编辑。
- **待补充位置** 列表收纳没有有效坐标的历史门店；补录保存后自动切到已定位列表并定位该门店。
- **门店管理 → 新增 / 编辑 → 地图选点 / 核对位置**：搜索地点、点击地图或拖动标记，核对详细地址并勾选确认，应用到表单后再保存门店。
- **门店管理 → 门店位置** 或地图中的 **补录位置 / 编辑位置**：确认后仅保存该门店的位置。
- 地址改动会取消位置确认；已有坐标的门店修改地址后，需要通过地图重新核对。

## 实现与边界

沿用 COOL Admin Vue 的静态菜单、keepAlive 页面、cl-dialog、cl-crud、cl-upsert、Element Plus 组件和 merchantRequest 认证及错误处理。没有查到项目及父目录适用的 AGENTS.md。

新增文件：

- `src/modules/merchant/map/store-map.ts`：类型、坐标判断、地图筛选白名单及商家地图接口。
- `src/modules/merchant/map/tencent-sdk.ts`：腾讯 GL SDK 按需加载、超时、失败重试。
- `src/modules/merchant/components/tencent-store-map.vue`：地图、营业状态标记、点聚合、选择联动、点击选点和拖动。
- `src/modules/merchant/components/store-location-picker.vue`：地点搜索、地址解析、反向解析、位置预览及明确确认。
- `src/modules/merchant/views/store-map.vue`：全量地图、筛选、统计、待补录列表和详情。

修改 `src/config/index.ts` 增加菜单；修改 `business-crud.vue` 接入门店表单选点和独立位置维护；`env.d.ts` 声明网页 Key 环境变量。

SDK 从 `.env.local` 的 `VITE_TENCENT_MAP_KEY` 读取，不在源码、测试说明中记录 Key。地点搜索、地址解析、反向解析全部通过商家后端；SDK 只负责地图绘制和交互。参考官方 [聚合文档](https://lbs.qq.com/webApi/javascriptGL/glDoc/glDocCluster) 和 [编辑器文档](https://lbs.qq.com/webApi/javascriptGL/glDoc/glDocEditor)。

严格使用文档中的 `/merchant/workspace/store/map` 全量接口，不传分页、merchantId 或跨商家选择。位置更新仅传 id/address/longitude/latitude；新增及完整编辑复用原 store/save。未改后端、运营端或店员权限，也未执行 Git 提交、推送。

坐标采用 GCJ-02，longitude 是经度、latitude 是纬度；仅 located=true 且有效的坐标绘制标记。0 经度、0 纬度均有效；空坐标不推算、不自动保存。搜索防抖 400ms，异步响应使用版本号隔离，取消及保存失败保留明确状态。

## 验证结果

- `npm run type-check`：通过。
- `npm run build`：通过；存在框架原有的大体积 chunk 提示。
- `node testing/store-map-contract.cjs`：通过，覆盖零坐标、空值/越界、located 标志、筛选白名单、查询编码和位置请求字段。
- Playwright + **真实腾讯 SDK**：底图、编辑器、点击选点、拖动标记通过；拖动和点击均更新坐标，未确认时禁止保存。
- 全量模拟接口 123 家门店（其中包含 0/0 坐标及待补录门店）：完整列表、数量、status=0、旧筛选响应隔离、搜索防抖通过。
- 地点选择和地址解析仅预览；保存失败保留预览，重试成功；位置更新字段检查通过。
- 新增门店把确认后的地址和 0/0 坐标传到原 store/save；编辑已有门店改地址后重新核对、保留原坐标、取消补录不写入，均通过。
- 真实 MarkerCluster 将 121 个密集门店聚合，自定义数字标记绘制通过。
- 无结果、地图数据接口失败/重试、SDK 加载失败时列表可用、SDK 重试恢复均通过。

业务写入通过浏览器模拟接口验证，没有改动真实门店数据；本次没有声称完成真实账号下数据库写入的端到端验收。

## 浏览器复核脚本

在独立 Playwright CLI 会话打开 `http://localhost:9001/login`，依次用 `run-code --filename=...` 运行：

1. `testing/map-live-setup.js`：注入测试会话并拦截所有 workspace 请求；真实加载地图 SDK。
2. `testing/map-live-interact.js`：真实地图点击及拖动。
3. `testing/map-browser-regression.js`：全量、筛选、预览、保存失败重试。
4. `testing/map-crud-regression.js`：新增、编辑与取消。
5. `testing/map-cluster-failure-regression.js`：真实聚合及 SDK 失败重试。
6. `testing/map-api-failure-regression.js`：地图数据接口失败重试。

脚本使用隔离的假登录和模拟业务数据，不可作为真实后端权限验收。运行前确保前端开发服务已启动；结束后关闭测试浏览器会话。地图加载仍依赖网络及网页 Key 域名授权。
