# 腾讯地图接入与验证

验证日期：2026-10-24。项目：cool-admin-vue-8.x。本次仅修改运营前端，没有修改后端接口，没有提交或推送 Git，没有写入或批量生成门店坐标。

## 入口和使用方法

左侧“商家管理 → 门店分布地图”已通过框架现有菜单页面添加。路由 `/merchant/storeMap`，文件 `modules/merchant/views/storeMap.vue`，排序号 5。其他环境可按这三个值新增菜单；不要重复创建。门店列表顶部也有地图入口，行内有“位置管理”，新增、编辑门店的详细地址旁有“地图选址”。

地图页支持关键词、所属商家、门店类型、营业状态筛选。统计数量来自专用地图接口的当前筛选结果；地图使用该接口的完整列表，不以普通门店分页替代。已定位门店可在地图和列表之间联动选择，点击数量聚合点可展开范围。营业中为绿色，停用为灰色，选中为蓝色。待补充位置单独列出，不绘制假位置。详情显示业务名称和状态文字。

新增、编辑表单中的选址只回填地址和经纬度，最后仍需保存外层门店表单。已有门店的“位置管理”使用位置补录接口，只有核对地址并勾选确认后点击“确认保存位置”才写入。关闭或取消不会写入。地图点击或拖动后先反查地址，失败时显示提示，可人工核对地址后再决定是否保存。不要将默认全国视野当成门店坐标。

## 配置和权限

网页地图 Key 从根目录 `.env.local` 的 `VITE_TENCENT_MAP_KEY` 读取，没有写入源码或本文。修改环境变量后需重启 Vite。网页 SDK Key 与后端地点服务配置彼此独立；底图能加载不代表后端地点搜索授权已正常。浏览器环境变量属于网页 SDK 使用配置，不能填写后端 Key 或签名密钥。

沿用框架的认证、错误处理和菜单权限。普通角色需按职责配置菜单和接口权限：`merchant:store:map`、`merchant:store:info`、`merchant:store:location:update`、`merchant:map:suggest`、`merchant:map:geocode`、`merchant:map:reverseGeocode`。新增、编辑门店仍使用原有新增、编辑权限。本次没有调整任何角色的授权范围。

## 接口和坐标

接口参数以 `D:/Graduation Project/api-docs/门店定位与腾讯地图接口.md` 为准。前端请求沿用 service.request，传入 admin 前缀。

- POST /admin/merchant/store/map：完整筛选结果和统计。
- POST /admin/merchant/store/location/update：已有门店确认位置后保存。
- GET /admin/merchant/map/suggest：地点关键词搜索，400ms 防抖。
- GET /admin/merchant/map/geocode：详细地址解析。
- GET /admin/merchant/map/reverseGeocode：地图点击或拖动后地址反查。

所有坐标均为 GCJ-02。longitude 是经度，latitude 是纬度。绘制要求 located=true 且两项坐标有效，零值合法，空值、缺失、越界不绘制。保存最多保留七位小数。历史空坐标正常保留。地点搜索与解析全部经过后端，没有使用网页 SDK 的地点搜索服务代替后端。较旧异步响应不能覆盖较新的输入或选点。地图加载失败可重试，保存失败保留用户选择。
