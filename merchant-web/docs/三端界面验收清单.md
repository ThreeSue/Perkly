# 券管家三端界面验收清单

设计基准：运营端「门店信息」。主色用于身份、主要动作和选中项，成功、待处理、危险按业务含义着色。列表保留清晰的名称、辅助信息和操作层级，表单按业务步骤组织。

以导航分组、菜单初始化、前端补充路由和实际账号为准。标注「依授权」的入口可能因账号而异；数据库中单独配置的菜单需与浏览器侧栏核对。每项在正常、窄窗口、长名称及其适用的悬停、聚焦、选中、禁用、加载、空结果、失败状态下检查。修改数据的操作使用测试记录。

状态：**已优化并验证** · **已检查、无需调整** · **待处理**。仅完成代码盘点或只打开首屏的项目仍为待处理，进展记在对应项。
