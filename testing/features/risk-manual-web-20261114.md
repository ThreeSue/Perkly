### 可重复的浏览器验收

1. 在管理端目录运行 node testing/risk-manual-fixture.mjs，用 Edge 打开 http://127.0.0.1:19049/__risk-fixture。
2. 进入「词库与规则」，确认词库结果和“当前使用管理词库”。
3. 预览整理，核对两条可应用、一条待核实不可选。最后一批不显示下一批按钮。只选归并行时应提示一并选择主记录。两行均选后确认，页面显示修正 1 条、归并 1 条。服务日志中的 ids 应为 [101,102]。
4. 打开入口追加 ?conflict=1 并重复预览、选中、确认。应提示重新预览，旧应用按钮消失。
5. 入口追加 ?stringId=1，复验超出 JS 安全整数范围的预览编号。
6. 入口追加 ?role=view。可读词库和巡检状态，隐藏词库写入和历史整理。
7. 选择「工作账号资料」并执行单批纯词库重扫，检查按对象及字段分别计数，手动填写下一批游标，不自动提交。

以上步骤使用回环内存夹具。Edge 已验证应用成功、409、只读入口、管理词库文案、末页、主记录依赖、巡检状态、重扫结果及下一批起点 12。截图为 testing/screenshots/risk-history-fixture-20261114.jpg。真实联调使用独立前端 19000、后端 18081 和已迁移的隔离库。
