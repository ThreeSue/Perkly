# 搜索风险监控

> 2026-11-12：本文件保留搜索阶段历史说明。当前已扩展为统一内容风险管控，接口与词库优先级以 [统一契约](统一内容风险管控契约-20261112.md) 为准；不再仅使用自建词匹配。

用户端请求仍走原门店、优惠券、附近门店及推荐搜索接口，不单独上报风险或传入 userId。登录用户取可信 APP 身份，游客 userId=null。记录原文、命中词、实际请求路径、创建时间。一次 HTTP 请求内同词只记一次，推荐内部翻页不会重复入库；不同请求不合并。

BLOCK：记录独立事务落库后返回业务 code=422，message=搜索内容包含不适宜词语，请修改后重试。前端显示提示并停止本次搜索，不自动重发。REVIEW：正常返回搜索结果，后台留待处理记录。ALLOW：完整搜索词经 NFKC 与大小写归一后精确匹配白名单才豁免；不是包含白名单片段即可绕过。关键词长度上限100字符。词库实时读取，停用立即影响下一次请求。

不会自动封号。后台复核 CONFIRMED 仅确认风险记录，封禁/解禁仍使用现有用户管理能力和权限。已封禁用户的有效旧 APP 登录凭证亦不能继续请求，不降级为游客；游客不计入去重账号统计。

## 平台后台

基础路径 /admin/search-risk，读取权限 search:risk:view，修改权限 search:risk:manage。只允许平台身份。

- GET /words：词条数组。
- POST /words/save：{id?,word,mode:BLOCK|REVIEW|ALLOW,enabled}，新增或修改；停用用 enabled=false。
- POST /words/delete：{id}，删除词条并审计；历史命中记录保留。
- GET /records?page=1&size=20&status=&userId=：{list,total}，size 1~100，列表含原文 content、matchedWords（JSON字符串数组）、source、userId、mode、status、createTime、operatorId、reason、handledAt。
- GET /records/detail?id=：单条风险记录。
- POST /records/resolve：{id,status:IGNORED|CONFIRMED,reason}，原因必填最多200字；只能处理 PENDING；并发以行锁串行，已处理返回409。
- GET /stats：{pendingRecords,pendingAccounts,confirmedAccounts}，账号数按非空 userId 去重，不等于记录数。
- GET /audit?page=1&size=20：{list,total}，词库修改、复核操作留操作人及时间。

三张增量表脚本 deploy/search-risk-20261112.sql，执行前备份；不内置默认敏感词，不修改现有账号状态。菜单 /workspace-admin/search-risk，页面模块 modules/workspace/views/search-risk.vue 由网页管理端任务实现。需要给运营角色分配上述权限。
